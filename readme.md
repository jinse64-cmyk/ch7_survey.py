# 📊 설문 데이터 분석 Streamlit 대시보드

구글 설문지 응답 원본(`survey_raw.csv`)을 체계적으로 정제하고, 기본 시각화 차트를 통해 핵심 지표와 집단별 차이를 분석할 수 있는 멀티페이지 Streamlit 애플리케이션입니다.

---

## 📁 프로젝트 디렉터리 구조

```text
my_streamlit_app/
├── Home.py                  # 메인 시작 페이지
├── pages/
│   ├── 1_데이터_정제.py      # 데이터 업로드, 전처리 파이프라인 및 CSV 내보내기
│   └── 2_그래프_분석.py      # 정제 데이터 요약 지표 및 4개 탭 그래프 분석
├── requirements.txt         # 필수 라이브러리 목록
└── README.md                # 프로젝트 안내 문서
```

---

## 🛠️ 주요 기능

### 1. 홈 (`Home.py`)
- 멀티페이지 내비게이션 가이드 제공
- 현재 세션 내 정제 데이터 적재 상태 확인

### 2. 데이터 정제 (`pages/1_데이터_정제.py`)
- **컬럼 표준화**: 설문 문항 열을 `타임스탬프`, `성별`, `학년`, `소속단과대학`, `AI사용시간`, `Q1`~`Q6`, `서술형`으로 축소 매핑
- **중복 행 제거**: 타임스탬프를 제외한 모든 항목이 일치하는 응답 필터링 (첫 번째 응답 유지)
- **학년 표준화**: 텍스트('일학년', '1학년')를 숫자(1~4)로 일괄 변환
- **단과대학 분류**: 키워드 기반 분류 (인문대학, 사회과학대학, 경제통상대학, 경영대학, 사범대학, 기타)
- **시간 단위 변환 및 이상치 제어**:
  - '1시간 30분'과 같은 혼합 문자열을 분 단위(90)로 환산
  - 사이드바 슬라이더를 통해 지정한 허용 범위 외 데이터 제거
- **결측치 처리 옵션**: 열별 결측치 현황 파악 및 사이드바 선택에 따른 '그대로 두기' / '행 삭제' 처리
- **역코딩 처리**: $Q6R = 6 - Q6$ 계산 컬럼 추가
- **데이터 공유 및 내보내기**: `st.session_state["clean_df"]` 저장 및 UTF-8 with BOM(`utf-8-sig`) CSV 다운로드 지원

### 3. 그래프 분석 (`pages/2_그래프_분석.py`)
- **세션 연동 및 수동 업로드**: 정제된 데이터가 세션에 없을 경우 직접 CSV 업로드 지원
- **요약 지표**: 유효 응답 수, 평균 AI 사용 시간, AI 윤리의식 종합 평균
- **정제 전후 비교**: 단과대학별 인원 변화 가로 막대 차트
- **4대 분석 탭**:
  1. **응답자 구성**: 성별, 학년별, 단과대학별 가로 막대 분포
  2. **문항별 평균**: 문항별 점수 가로 막대 차트 및 수치 표
  3. **집단 비교**: 학년별/단과대학별 응답자 수 및 소수점 둘째 자리 평균 통계
  4. **사용 시간과 점수**: 사용 시간 구간별 종합 점수 관계 분석

## 🚀 설치 및 실행 방법

### 1. 가상환경 생성 및 활성화 (권장)
```bash
# 가상환경 생성
python -m venv venv

# 가상환경 활성화 (Windows)
venv\Scripts\activate

# 가상환경 활성화 (macOS / Linux)
source venv/bin/activate
```

### 2. 필수 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 3. 애플리케이션 실행
```bash
streamlit run Home.py
```
브라우저가 열리면 사이드바의 **1_데이터_정제** 페이지로 이동하여 CSV 파일을 업로드하고 정제를 진행하세요.
